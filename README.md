## Projects

**MSc Thesis – Counter-UAV Laser Gimbal** *(2026)*
A 2-DOF gimbal that detects and tracks a drone in real time and keeps a laser on target.
- Integral sliding-mode controller (yaw and pitch), tuned with a genetic algorithm in MATLAB/Simulink
- YOLO-based drone detection with an Extended Kalman Filter for target-state estimation
- Real-time hardware loop: Pixhawk IMU and servos over MAVLink, Python bridge to Simulink over TCP at 1 kHz
- Laser-exposure analysis: beam overlap, fluence accumulation and sensor-vulnerability thresholds

**Turbojet Compressor Optimisation**
Radial impeller and diffuser design for a small turbojet, validated with CFD.

**UAS Certification Tool (ANAC)**
Interactive aerodynamic failure simulations to support UAS safety assessment.
